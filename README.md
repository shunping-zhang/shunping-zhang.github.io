# 我的个人主页

纯 HTML + CSS 手写的单页站点，部署在 GitHub Pages 上。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构（写什么内容） |
| `style.css` | 页面样式（长什么样） |

## 怎么改

1. 用记事本或 VS Code 打开 `index.html`
2. 搜索「你的名字」，替换成你自己的名字（首屏大标题里的 `<span class="accent">` 和头像里的那个字也要改）
3. 改「关于我」那两段文字，写成你自己的经历
4. 技能列表 `<ul class="chips">` 里增减 `<li>`
5. 联系方式里的邮箱换成你自己的

改完刷新浏览器就能看到效果，不需要安装任何东西。

## 换配色

打开 `style.css`，最上面 `:root` 里那几行就是全站颜色。
改 `--accent` 的值就能换掉所有按钮和链接的颜色，比如：

- 蓝 `#2f5bea`
- 绿 `#1f9d55`
- 橙 `#e8730c`
- 紫 `#7c3aed`
